Privacy Policy

Private Media Vault uses Google OAuth and Google Drive to access files used by the application.

The application requests the Google Drive drive.file scope. This permission is used to access files created by or used with Private Media Vault.

Private Media Vault does not sell Google user data or use Google user data for advertising.

Media stored for Private Media Vault is encrypted before storage. Decryption credentials and plaintext media are not intentionally published through this website.

This website provides information about Private Media Vault and its OAuth configuration.
